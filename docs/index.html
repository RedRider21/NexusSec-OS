Come funziona

Niente bloat: ogni tool arriva dal canale giusto.

Il catalogo e' la fonte di verita'. Al primo avvio di uno strumento, NexusSec sceglie il metodo e lo installa isolato.

apk

Nativo Alpine

Pacchetti dai repo Alpine, piu' i nostri firmati via GitHub Pages.

container

Podman

Tool pesanti in container isolati: Metasploit, ZAP, WPScan.

kali

Kali-rolling

Un ambiente Kali condiviso: ~600 tool dell'arsenale, a un apt di distanza.

pip · git

Python

Strumenti moderni (Certipy, bloodyAD, mitm6, Villain) via pipx.

x86_64 (BIOS + UEFI) · ARM64 aarch64 (UEFI)

Provala adesso.

Due immagini ISO ~0.5 GB: x86_64 (PC Intel/AMD, VirtualBox/QEMU) e ARM64 aarch64 (Apple Silicon, SBC e VM ARM con QEMU/UTM, boot solo UEFI). VM Linux 64-bit, 2–4 GB di RAM, boot dall'ISO. Splashscreen flat con barra di caricamento, poi il desktop e' pronto. Su portatile, WiFi interno (incluse le schede Intel) e cablato pronti all'uso.
