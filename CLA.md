## 4. Come accettare (DCO)

Per contributi via Git, firma ogni commit con il **Developer Certificate of
Origin** aggiungendo in coda al messaggio:

```

```

(si ottiene con `git commit -s`). La firma attesta che accetti questo CLA e il
DCO. Per contributi rilevanti può essere richiesta una conferma esplicita via
e-mail a deplano.d@gmail.com.
